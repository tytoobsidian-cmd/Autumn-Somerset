# Somerset in autumn

An interactive, animated single-page site about the autumn woodland ecosystem of Somerset, UK.

- Clickable woodland hotspots with species notes
- September / October / November switch that changes the scene
- Interactive food web
- Somerset habitats: Exmoor, Quantocks, Levels, Mendips

Everything lives in `index.html` (the photo is embedded). Open it in a browser, or host it with GitHub Pages.
